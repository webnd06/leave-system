# Vue 3 + Vite
## git初始化 及 推送GitHub Repository
```
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/webnd06/leave-system.git
git push -u origin main
```
## 部署
```
npm run build
npm run deploy
```
